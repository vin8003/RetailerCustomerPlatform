## The retailer journey at a glance

```
Log in → Dashboard → POS for walk-ins / Orders for online
    → Products & Purchases for stock → Customers & Offers for relationships
```

## Before you start

- Retailer account with shop access code (from OrderEasy onboarding)
- Browser on phone or computer — [retailer.ordereasy.win](https://retailer.ordereasy.win)
- Optional: Android phone for the **scanner app** when building catalog

## Sidebar menu (main sections)

| Menu item | Purpose |
|-----------|---------|
| Overview | Dashboard and insights |
| POS | Walk-in billing |
| Purchases | Stock received from suppliers |
| Khata / Suppliers | What you owe suppliers |
| Products | Your catalog |
| Categories | Organise products |
| Orders | Online customer orders |
| Reviews | Customer ratings |
| Customers | CRM and credit |
| Offers | Promotions |
| Profile | Shop settings |
| Operating Hours | Open/close schedule |
