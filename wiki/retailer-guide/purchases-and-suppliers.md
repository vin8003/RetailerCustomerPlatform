# Purchases and suppliers

When stock arrives from a **supplier** (wholesaler, distributor, company van), record it in OrderEasy so inventory and accounts stay correct.

## Why record purchases?

| Benefit | Explanation |
|---------|-------------|
| **Accurate stock** | Shelf quantity matches system |
| **Cost tracking** | Know margin per product. Purchase-role staff can see each supplier’s last billed cost for a product, and a margin% on the product list, product detail, POS catalog, and a dedicated preview — selling price versus the product’s draft cost or last purchase cost. If there is no cost yet, margin stays blank — it is not shown as zero. Cashiers do not see margin on the catalog. |
| **Supplier khata** | Track what you owe each supplier |
| **Batch history** | Link sales to purchase lots |

## Recording a purchase

1. Open **Purchases** → **New purchase**
2. Select **supplier** (or add new supplier)
3. Add line items — product, quantity, cost price
4. Enter invoice number and date if you have them
5. Attach **bill photo** optional but useful for records
6. Save

Stock increases automatically for each line.

## Suppliers

**Suppliers** is your address book of wholesalers:

| Field | Example |
|-------|---------|
| Name | ABC Distributors |
| Phone | Optional — for your reference |
| Address | Optional |
| GSTIN | Optional. The same GSTIN cannot be used twice in one shop group. |
| Payment terms | Optional (for example Net 30). Only purchase-role staff can change terms. |
| Active | Turn off a supplier you no longer buy from. Inactive suppliers cannot be picked on a **new** purchase. |

Mobile number is **not required** — you can track suppliers by name alone. GSTIN is also optional.

Purchase orders (PO / GRN matching) are a later step. Today, new stock-in still uses **Purchases**. The same active-supplier rule will apply when POs arrive.

## Supplier khata (what you owe)

Many kirana shops buy on **credit from suppliers** and pay weekly or monthly.

**Supplier ledger** (khata) shows:

- Each purchase added to balance
- Payments you made
- **Remaining due** per supplier

When you pay a supplier:

1. Open supplier ledger
2. Record **payment** with amount and date
3. Balance reduces

This is separate from **customer credit** (what customers owe you).

## Purchase returns

If you return goods to a supplier:

- Open the purchase or use **return** flow
- Stock decreases
- Supplier balance adjusts
- Returned lines show the product brand when the SKU has one

Keep paperwork aligned with physical returns.

## Link to products

When purchasing:

- Link to existing products when possible
- New products from purchase can be added to catalog
- Batch tracking creates a new batch per purchase line when enabled

## Tips

| Tip | Practice |
|-----|----------|
| Enter purchases same day goods arrive | Stock stays trustworthy |
| Photo of bill | Helps during disputes |
| One supplier record per real vendor | Cleaner khata |
| Reconcile khata monthly | Match with supplier statements |
