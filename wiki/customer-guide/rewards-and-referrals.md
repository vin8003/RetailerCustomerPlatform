# Rewards and referrals

Many shops on OrderEasy run **loyalty programmes** — earn points when you order and use them for discounts later.

## Loyalty points

### How you earn points

Depends on what the shop has set up. Common patterns:

- Points per rupee spent on completed orders
- Bonus points during promotions
- Referral bonuses (see below)

Points are **per shop**. Points at Shop A cannot be used at Shop B.

### How to see your balance

Go to **Rewards** in the customer app (or find rewards in your profile).

You will see:

- Current point balance for each shop you have ordered from
- Transaction history (earned and spent)
- Any active referral codes

### How to redeem points

Usually at **checkout**:

1. Add items to cart
2. On checkout screen, look for **Apply reward points**
3. Choose how many points to use (within shop rules)
4. Discount applies to order total

Some shops set minimum order or maximum redemption limits.

## Referral codes

Shops may give you a **referral code** to share with friends and family.

| Who | Benefit (typical) |
|-----|-------------------|
| **You (referrer)** | Bonus points when someone uses your code |
| **New customer** | Welcome discount or bonus points on first order |

### How to use a referral code

If a friend shared a code:

1. Go to **Rewards** or signup flow
2. Enter their referral code
3. Complete your first order from that shop

Rules vary by shop — check the Rewards page for details.

## Offers vs reward points

| Type | What it is |
|------|------------|
| **Shop offer** | Automatic discount (e.g. 10% off, buy 2 get 1) — applied by shop rules |
| **Reward points** | Currency you accumulate and choose to spend |

Both may apply on the same order depending on shop settings.

## Tips

- Order from the same shop regularly to build points faster
- Check Rewards before checkout — you might have enough for a discount
- Referral codes usually work only for **new customers** at that shop
