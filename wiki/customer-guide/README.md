## The customer journey at a glance

```
Open app → Allow location → See nearby shops → Pick YOUR shop
    → Browse products → Add to cart → Checkout → Track order → Rate / earn rewards
```

![Customer journey](../../docs/visuals/customer-journey.jpg)

*Illustration: the main steps from discovering a shop to completing an order.*

## Before you start

- You need a smartphone or computer with internet
- You should know **which local shop** you want to order from (or be willing to pick one nearby)
- Payment is usually **Cash on Delivery** or **UPI** — have your method ready at checkout
