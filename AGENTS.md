# Agent notes (OrderEasy backend)

Canonical documentation is **Git**, in [`docs/`](docs/DOCUMENTATION.md) and the user-facing **[`wiki/`](wiki/README.md)**.

## For product / user questions

1. Start at [`wiki/README.md`](wiki/README.md) — help centre for retailers and customers (plain language, end to end).
2. Use [`wiki/SUMMARY.md`](wiki/SUMMARY.md) for the full table of contents.

## For engineering / architecture

1. Read [`docs/DOCUMENTATION.md`](docs/DOCUMENTATION.md) for source-of-truth rules.
2. Read [`docs/00-INDEX.md`](docs/00-INDEX.md) to find a topic.
3. For a Jira key, open [`docs/tickets/`](docs/tickets/README.md) first, then follow `durable_docs` to the lasting page.
4. Update knowledge with a Git PR. Do not make GitBook or Confluence the lasting edit.
5. Jira is work/status only. Keep existing Confluence links on issues.

**Wiki** = human-friendly guides (customers, retailers, scanner, FAQ, full project map).  
**Docs** = architecture, flows, ADRs, requirements, tickets, visuals.

GitBook is optional presentation. A clone of this repo must be enough to understand the product and how it is built.
