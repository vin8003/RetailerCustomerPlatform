# Agent notes (OrderEasy backend)

Canonical documentation is **Git**, in [`docs/`](docs/DOCUMENTATION.md).

1. Read [`docs/DOCUMENTATION.md`](docs/DOCUMENTATION.md) for source-of-truth rules.
2. Read [`docs/00-INDEX.md`](docs/00-INDEX.md) to find a topic.
3. For a Jira key, open [`docs/tickets/`](docs/tickets/README.md) first, then follow `durable_docs` to the lasting page.
4. Update knowledge with a Git PR. Do not make GitBook or Confluence the lasting edit.
5. Jira is work/status only. Keep existing Confluence links on issues.

GitBook is optional presentation. A clone of this repo must be enough to understand architecture, flows, and extracted requirements.
