# OE-136 F-0030 — ProductBatch with expiry (thin slice)

Work snapshot. Durable: [product-batch-expiry.md](../requirements/product-batch-expiry.md).

Problem: `ProductBatch` had batch_number, prices, quantity — no expiry. Pharmacy/grocery lots need expiry storage, FIFO by earliest expiry at sale/pick, and a default block on expired sales.

Done in this change (EXTEND, one slice):

- Optional `ProductBatch.expiry_date` (null until filled). No `mfg_date` (field was not half-there).
- `reduce_quantity` FIFO: earliest dated saleable batch, **nulls last**, then `created_at`. Expired (`expiry_date < today`) cannot sell, including explicit POS `batch_id` and `allow_negative` leftover.
- Expiry create/change on product update requires existing `inventory.adjust` (echo OK). Bulk does not write expiry. No new permission code.
- Tenancy unchanged: retailer-scoped get (404 deny).

Out of scope: LIFO/MRP engines, org policy model, FE receiving/POS pickers, `StockMovement` SoT cutover, E16 expiry reports.
