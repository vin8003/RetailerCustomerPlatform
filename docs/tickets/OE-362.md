# OE-362 F follow-on — optional `is_fragile` on product serializer

Work snapshot. Durable: [product-is-fragile.md](../requirements/product-is-fragile.md).

Product list/detail already expose availability bools. They omitted optional `is_fragile`. Product has no `is_fragile` column on this stack — do not invent one. CTO overnight lock is this EXTEND only: echo `is_fragile` when the product attribute exists; otherwise `null`. **Avoid Meta** — do not add the key to `Meta.fields`.
