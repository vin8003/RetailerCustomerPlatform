# OE-293 F follow-on — `original_price` on retailer search

Work snapshot. Durable: [search-original-price.md](../requirements/search-original-price.md).

List/detail serializers and POS `no_page` already expose top-level `Product.original_price`. `ProductSearchSerializer` Meta.fields omitted it after OE-287/290/291 (`brand_name` + `barcode` + `category_name`). This slice only returns top-level `original_price` on search.

| AC | Before this slice | After |
|----|-------------------|--------|
| Search row includes `original_price` | List/detail/POS only | **EXTEND** — same model value |
| Null/absent cost stays null | List/detail/POS pass through | same on search (do not coerce to 0) |
| Auth/tenancy / public catalog | Shop-scoped retailer GET | unchanged; public search inherits via shared serializer |
| Price write / margin invent | Existing / invent | still out of scope |

- Tests: search parity with list/detail/POS, null stays null, public list + public search, OE-287 `brand_name` + OE-290 `barcode` + OE-291 `category_name` light non-regression, auth denied, shop-scoped tenancy
