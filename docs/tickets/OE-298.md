# OE-298 F follow-on — `discounted_price` on retailer search

Work snapshot. Durable: [search-discounted-price.md](../requirements/search-discounted-price.md).

List/detail serializers already expose top-level `Product.discounted_price` (property = `price`) as a read-only `DecimalField`. POS `no_page` already includes `discounted_price` (`p.discounted_price or p.price`). `ProductSearchSerializer` Meta.fields omitted it after OE-287–295 (`brand_name` + `barcode` + `category_name` + `original_price` + `is_seasonal` + `product_group`). This slice only returns top-level `discounted_price` on search.
