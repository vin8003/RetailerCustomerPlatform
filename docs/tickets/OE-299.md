# OE-299 F follow-on — `is_featured` on retailer search

Work snapshot. Durable: [search-is-featured.md](../requirements/search-is-featured.md).

List/detail serializers already expose top-level `Product.is_featured`. `ProductSearchSerializer` Meta.fields omitted it after OE-287–298 (`brand_name` + `barcode` + `category_name` + `original_price` + `is_seasonal` + `product_group` + `discounted_price`). This slice only returns top-level `is_featured` on search.

POS `no_page` does not expose `is_featured`. This slice does not add it there.
