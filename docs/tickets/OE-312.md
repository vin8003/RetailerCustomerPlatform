# OE-312 F follow-on — `is_in_stock` on retailer search

Work snapshot. Durable: [search-is-in-stock.md](../requirements/search-is-in-stock.md).

List/detail serializers already expose top-level `Product.is_in_stock` (model `@property`, declared as read-only `BooleanField`). `ProductSearchSerializer` Meta.fields omitted it after OE-287–303 (`brand_name` + `barcode` + `category_name` + `original_price` + `is_seasonal` + `product_group` + `discounted_price` + `is_featured` + `is_active` + `is_available`). This slice only returns top-level `is_in_stock` on search.

`is_in_stock` is not a DB column, so search uses the same list/detail declaration (`BooleanField(read_only=True)` + Meta field). Not a MethodField. No extra queryset work.

POS `no_page` does not expose `is_in_stock`. This slice does not add it there.

Public list/search querysets still filter `is_available=True` (unchanged). They do not filter `is_in_stock`. This slice does not invent stock math or change those filters.

## Gap list (scout)

| AC | Before this slice | After |
|----|-------------------|--------|
| Search row includes `is_in_stock` | List/detail only | **EXTEND** — same property value |

## Done in this change (EXTEND, one slice)

- `ProductSearchSerializer` exposes `is_in_stock` (`Product.is_in_stock`) the same way list does (read-only `BooleanField` + Meta field)
- Tests: search parity with list/detail for true and false, false echo on the shared serializer, public list + public search (public still omits unavailable SKUs; out-of-stock available SKUs inherit `false`), OE-287 `brand_name` + OE-290 `barcode` + OE-291 `category_name` + OE-293 `original_price` + OE-294 `is_seasonal` + OE-295 `product_group` + OE-298 `discounted_price` + OE-299 `is_featured` + OE-300 `is_active` + OE-303 `is_available` light non-regression, auth denied, shop-scoped tenancy

Out of scope: stock write/admin, invent stock math, FE, POS `no_page` field add, search queryset change, OE-102, GST rebuild, inventory.adjust, timeline/OFD/khata/UPI/slots, pack write, merge, Jira Done, live `*.ordereasy.win`.
