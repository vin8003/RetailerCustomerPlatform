# OE-182 F-0006 — Retailer and customer API versioning

Work snapshot. Durable: [api-versioning.md](../requirements/api-versioning.md).

Problem: DRF existed but was not a productized API platform with keys, scopes, or partner versioning.

Done in this change (EXTEND):

- Org-scoped `OrgApiKey` + `OrgApiKeyAudit`; hashed secrets; revoke-on-next-request
- Versioned partner scope catalog; deny-by-default enforcement on `/api/v1/partner/*`
- JWT management under `/api/retailer/org/<id>/api-keys/` gated by `api_keys.manage`
- Version policy `GET /api/v1/`; JWT aliases `/api/v1/retailer/`, `/api/v1/customer/`
- Rate limit throttle for API keys; cross-tenant + 401/403 + audit tests

Out of scope: F-0118 partner catalog/order rewrite, OE-99 full audit product, POS/catalog/stock/khata rewrites, customer-app staff screens, deploy.
