# KAN-276 Thin BE — optional `is_perishable` on product serializers

Work snapshot. Durable: [optional-is-perishable.md](../requirements/optional-is-perishable.md).

`Product` has no `is_perishable` column. Adding it to serializer `Meta.fields` would break ModelSerializer. This slice echoes the value from `to_representation` only when `Product._meta` has that field.

| Missing model field | n/a | omit key, do not raise |
| Model / migration / writes | None | still out of scope |
