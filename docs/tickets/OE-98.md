# OE-98 F-0002 — Shop staff roles

Work snapshot. Durable: [shop-staff-roles.md](../requirements/shop-staff-roles.md).

Problem: shop owner was the only actor; cashiers need named roles with enforceible 403s.

Done in this change (NEW):

- Versioned permission catalog + Admin/Cashier bootstrap on every org (owner = full admin)
- `OrgRole` / `OrgStaffMembership` / `OrgStaffRoleAudit` bound to `AUTH_USER_MODEL`
- Staff APIs under `/api/retailer/org/<id>/{roles,staff,permissions}/`
- Cashier without `org.update` / `staff.manage` → **403**, resource unchanged
- Live DB permission checks so role changes apply on the next request
- Cross-tenant + 401/403 tests
