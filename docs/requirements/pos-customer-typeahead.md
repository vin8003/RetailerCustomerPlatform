# POS customer typeahead

- **Ticket:** [KAN-29](https://vin8003.atlassian.net/browse/KAN-29) · [snapshot](../tickets/KAN-29.md)
- **App:** `retailer_ordereasy_njs` POS · live https://retailer.ordereasy.win

Typing in POS billing lists **only this retailer’s customers**, including **name**. Other app users must not appear after a partial phone (e.g. three digits).

Use existing retailer–customer mapping / customer search. Do not add a global user directory, new customer product, or delivery scope.
